# [톡벨] 치환 변수 8개 확장 및 입력 제한

- **요청일**: 2026-08-13
- **대상 화면**: 일반문자 / 광고문자 / 선거문자 발송, 알림톡 발송, 브랜드 메시지 발송, 알림톡 템플릿 등록
- **확인 URL**: https://spec-pearl-mu.vercel.app

---

## 1. 변수는 최대 8개까지, 등록된 변수만 사용 가능

### 1-1. 변수 개수 확장 (3개 → 8개)

변수 삽입 버튼과 수신자 표가 `변수1~3`까지만 제공되고 있었습니다. **`변수1~8`까지 확장**합니다. 9개 이상은 제공하지 않습니다.

### 1-2. 사용 가능한 변수 (고정)

```
#{이름}   #{전화번호}   #{변수1} ~ #{변수8}
```

- 위 10개는 모두 **변수 삽입 버튼으로 제공**합니다. 발송 화면과 **알림톡 템플릿 등록 화면** 모두 동일합니다.
- **변수 항목명은 고정이며 이용자가 수정할 수 없습니다.** 업로드한 엑셀의 컬럼명이 무엇이든 화면의 항목명은 `이름 / 전화번호 / 변수1~8`로 표시되고, 값만 해당 컬럼에 매핑됩니다.

### 1-3. 등록되지 않은 변수 입력 차단

메시지 본문에는 **버튼으로 제공하는 변수만** 입력할 수 있습니다.

| 구분 | 예시 |
|---|---|
| 사용 가능 | `#{이름}` `#{전화번호}` `#{변수1}` `#{변수2}` … `#{변수8}` |
| 사용 불가 | `#{주문번호}` `#{송장번호}` 등 임의 변수명, `#{변수9}` 이상 |

**동작**

1. 본문 입력 중 허용되지 않은 변수가 감지되면 입력창 아래에 경고를 표시합니다.

   > ⚠️ 사용할 수 없는 변수입니다: `#{주문번호}`, `#{송장번호}`
   > 변수는 버튼으로 제공하는 `#{이름}`, `#{전화번호}`, `#{변수1}` … `#{변수8}` 만 사용할 수 있습니다.

2. 해당 변수가 남아 있는 상태로 **발송하기를 누르면 발송을 차단**합니다.
   알림톡 템플릿 등록 화면에서는 동일하게 **검수 신청을 차단**합니다.

> 사유: 등록되지 않은 변수는 수신자 표에 대응하는 컬럼이 없어 치환되지 않고 `#{주문번호}` 문자열 그대로 발송됩니다.

## 2. 수신번호 영역 항목명 및 가로 스크롤

### 2-1. 항목명 고정

수신번호 영역의 표 항목명을 아래와 같이 **고정 표기**합니다.

```
순번 | 이름 | 전화번호 | 변수1 | 변수2 | 변수3 | 변수4 | 변수5 | 변수6 | 변수7 | 변수8
```

- 템플릿에 어떤 변수가 있든 항목명은 바뀌지 않습니다.
- 템플릿의 변수는 표의 해당 변수 컬럼 값으로 치환되어 발송됩니다.

### 2-2. 가로 스크롤바 노출

변수가 8개로 늘면서 표가 화면 폭을 넘칩니다.

- 열을 좁혀 글자가 줄바꿈되지 않도록 최소 너비를 유지합니다.
- 표가 가로로 넘칠 경우 **표 영역 하단에 가로 스크롤바를 노출**합니다.
- 스크롤은 표 안에서만 발생하며, **페이지 전체가 가로로 밀리지 않습니다.**

## 연계 변경 (참고)

주소록이 `변수1~3`까지만 보관하고 있어 **주소록 불러오기로는 3개까지만 채워집니다.** 8개를 모두 활용하려면 주소록도 `변수1~8`로 맞춰야 하며, 이번에 함께 반영했습니다. (엑셀 업로드·엑셀 샘플 파일 포함)
